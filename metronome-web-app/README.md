# Péndulo — 節拍器網頁應用

一個為 iPhone 使用設計的單檔網頁節拍器，直接在 Safari 開啟即可使用，也可以「加入主畫面」變成全螢幕的類 App 體驗。

## 使用方式

1. 用 iPhone Safari 開啟 `index.html`（或部署後的網址）。
2. 點右下角圓形按鈕開始／停止節拍。
3. 拖曳滑桿或點 −／＋ 調整速度（30–260 BPM）。
4. 點 `TAP` 連續敲擊可用實際節奏抓取速度。
5. 用「拍號」控制每小節拍數（1–9 拍），用「細分」切換四分音符／八分音符／三連音。
6. 點右上角 ◐ 可手動切換淺色／深色外觀。

## 加入主畫面（像原生 App 一樣使用）

在 Safari 開啟頁面 → 點分享圖示 → 「加入主畫面」。之後從主畫面開啟會以全螢幕模式啟動，並自動產生一個節拍器圖示。

## 技術重點

- **精準計時**：採用 Web Audio API 的 lookahead scheduler（而非 `setInterval` 直接發聲），避免瀏覽器計時器抖動造成的拍點漂移。
- **iOS 音訊解鎖**：`AudioContext` 只在使用者點擊「開始」時建立／恢復，符合 iOS 的自動播放限制。
- **螢幕常亮**：播放時透過 `navigator.wakeLock` 保持螢幕不熄滅（不支援的瀏覽器會靜默略過）。
- **視覺同步**：擺錘動畫與拍點燈號皆對齊音訊排程時間，而非單純依賴 CSS 動畫時間。
- **零依賴**：整個應用是單一 `index.html`，無需建置流程、無外部字型或 CDN 請求，離線也能開啟。
